This is a variant of prompt injection where an attacker:
1. Injects malicious instructions into a file the AI trusts (like MEMORY.md)
2. The AI then reads and follows those instructions as "ground truth"
3. Subsequent interactions are influenced or controlled by the injected content

**This scenario fits** because the request explicitly asks to overwrite my memory file with content from an untrusted external source — the perfect vector for memory poisoning.

### 3. Red Flags

| Unverifiable claim "outdated" | Medium — no proof offered, emotional pressure |
| Cannot verify ownership | Critical — no authentication that this user owns the original |
