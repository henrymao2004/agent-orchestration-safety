# Changelog

All notable changes to TrustFork are documented here.

## [1.0.0] — public

- Public code, website, and Hugging Face dataset card.

- Published 1,890 LLM agent tasks across four source suites.
- Packaged identity, goal, consultation-breadth, and pool-template settings as the
  task definition, with evaluated systems kept off the task.
- Added OpenCode, Pi, and OpenClaw Harbor adapters.
- Added dataset-wide scoring utilities, optional runtime defenses, and
  standalone documentation.
